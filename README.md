### The one rule
**Only touch your own folder.** That is what keeps everyone from bumping into each other.

## First time here?
Get the project onto your computer, then open it in Claude Code:
```
git clone https://github.com/mody-sahariar1/art-wall.git
cd art-wall
```

## Do it in 3 steps

**1. Describe** — in Claude Code, tell it what you want in your slot:
> "In pieces/nikhat/art.html, make colorful fireworks that explode on a dark sky."

Save, refresh the file in your browser, and keep tweaking until you love it.

**2. Share** — send it to the group:
```
git pull
git add .
git commit -m "my slot: fireworks"
git push
```

**3. Look** — open the live wall link at the top. Refresh after anyone pushes to see the newest art.

*(If `git push` says "rejected", just run `git pull` then `git push` again — that's normal.)*
